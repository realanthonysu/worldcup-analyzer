# 赛前模式「五件套」

对下一场对手进行深度分析。其余场次以表格概览。

## 一、赛事概览

```
# {国旗emoji} $0 | 2026 世界杯 {组别} 第 {N} 轮
📅 {日期} {时间} | {场地} | vs {对手}

{一段话概述：两队在小组中的形势、本场的战略意义}
```

同时输出该队全部小组赛赛程表：

| 轮次 | 日期 | 对手 | 场地 | 状态 |
|------|------|------|------|------|
| 第1轮 | 6/15 | vs 沙特 | ... | 待踢 |
| 第2轮 | 6/20 | vs 摩洛哥 | ... | **本轮** ← |
| 第3轮 | 6/25 | vs 德国 | ... | 待踢 |

## 二、双方预计首发

搜索两队最新大名单、伤停信息、近期热身赛首发（按降级链执行）：

```
# 第一级：精准中文
query: "{队A} 2026 世界杯 大名单 首发 阵容 伤停"
query: "{队B} 2026 世界杯 大名单 首发 阵容 伤停"
# 命中标准：权威媒体有具体人名列表
# 未命中 → 第二级

# 第二级：精准英文
query: "{team A} 2026 FIFA World Cup squad lineup injuries"
query: "{team B} 2026 FIFA World Cup squad lineup injuries"
# 命中标准：FIFA/BBC/Guardian 等有具体阵容
# 未命中 → 第三级

# 第三级：宽泛搜索
query: "{队A} 2026 世界杯 阵容"
query: "{team A} 2026 World Cup squad"
# 仅确认大名单，首发标"基于大名单推测"
# 未命中 → 兜底声明
```

门将数据（必选搜索，两级降级）：

```
# 第一级：中文
query: "{队A} 门将 2026 世界杯 国家队数据 履历"
query: "{队B} 门将 2026 世界杯 国家队数据 履历"
# 命中标准：有具体出场数和世界杯履历
# 未命中 → 第二级

# 第二级：英文
query: "{team A} goalkeeper 2026 World Cup national team caps"
query: "{team B} goalkeeper 2026 World Cup national team caps"
# 未命中 → 标"待官方确认"
```

输出阵型对比表：

| 位置 | {队A} ({阵型}) | {队B} ({阵型}) |
|------|----------------|----------------|
| GK   |                |                |
| CB   |                |                |
| ...  |                |                |

标注：关键缺阵球员、替补席值得关注的球员。

**门将焦点**：列出两队首发门将的国家队出场数、世界杯履历。数据必须来自搜索结果，无把握时标注"待官方确认"。

## 三、战术推演

基于双方阵型和球员特点，分析：

- **控球方 vs 反击方**：谁更可能控球？谁打反击？
- **关键对位**：最有看点的 2-3 个位置对抗（如"阿根廷左路 vs 阿什拉夫"）
- **攻防焦点**：两队最可能的进攻发起区域和防守薄弱环节
- **X 因素**：可能改变比赛走势的变量（天气、裁判风格、主场氛围等）

用战术板风格的文字描述，必要时用简单阵型图示意。

## 四、世界杯历史交锋

仅限世界杯正赛范围内的 H2H 记录（两级降级）：

```
# 第一级：中文
query: "{队A} vs {队B} 世界杯 历史交锋"
# 命中标准：有具体年份/比分/进球者
# 未命中 → 第二级

# 第二级：英文
query: "{team A} vs {team B} World Cup head to head"
# 未命中 → 说明"两队在世界杯赛场上从未交手"
```

| 年份 | 阶段 | 比分 | 进球者 | 备注 |
|------|------|------|--------|------|
| 1986 | 1/8  | 1-0  | 布朗   | 马拉多纳助攻 |

若无世界杯交锋记录，说明"两队在世界杯赛场上从未交手"，补充双方各自的世界杯最佳战绩作为背景。

## 五、典故与花絮

为本场比赛增添故事性和趣味性。每个典故标注来源。

**来源策略**：主力使用 LLM 内置知识，辅以 web search 验证和补充（LLM 知识为主，搜索为辅，不做降级）。

```
query: "世界杯 $0 历史 经典时刻 传奇"
query: "2026 世界杯 $0 故事 花絮"
```

覆盖以下维度（有料则写，没料跳过）：

- **球队传承**：该队的世界杯 DNA（如巴西的进攻传统、德国的大赛气质）
- **球星故事**：当家球星的世界杯生涯轨迹、关键节点
- **城市/场地**：比赛场地的背景故事、所在地的足球文化
- **冷门/纪录**：与两队相关的世界杯纪录或冷门事件
- **本届看点**：与 2026 世界杯直接相关的叙事（卫冕、告别、新星首秀等）

## 淘汰赛变体

当路由判定为淘汰赛时，第一节替换为：

```
# {国旗emoji} $0 | 2026 世界杯 {阶段}（如 1/16 决赛、1/8 决赛、1/4 决赛等）
📅 {日期} {时间} | {场地} vs {对手}

{一段话概述：两队晋级路径、本场的战略意义}
```

淘汰赛赛程表替换为晋级路径表：

| 阶段 | 对手 | 比分 | 状态 |
|------|------|------|------|
| 小组赛第1轮 | ... | ... | 已踢 |
| 小组赛第2轮 | ... | ... | 已踢 |
| 小组赛第3轮 | ... | ... | 已踢 |
| **1/16 决赛（Round of 32）** | ... | ... | 已踢 / **本轮** ← |
| **1/8 决赛（Round of 16）** | 待定 | — | 待踢 |
| 1/4 决赛 | 待定 | — | 待踢 |
| 半决赛 | 待定 | — | 待踢 |
| 决赛 / 三四名决赛 | 待定 | — | 待踢 |

> 2026 世界杯淘汰赛从 Round of 32（1/16 决赛）开始，共 5 轮淘汰赛 + 三四名决赛。

其余四节（首发/战术/H2H/典故）结构不变。

## 赛事未开始变体

当路由阶段一判定赛事尚未开始**且参赛验证确认该队参加本届世界杯**时，使用以下结构替代五件套。这是一个"球队巡礼"式的前瞻分析，不做针对某一场的深度对位分析。

> 若参赛验证确认该队未参加本届世界杯，不走此变体，进入 [references/historical.md](references/historical.md) 历史模式。
>
> 若输入验证（阶段零）已将输入拒收（俱乐部、非足球实体、退役球员等），不会到达此变体。

### 输出结构

```
# {国旗emoji} $0 | 2026 世界杯前瞻
📅 赛事日期：2026-06-11 ~ 2026-07-19 | {组别}

{一段话概述：该队在本届世界杯的定位和看点}
```

#### 一、分组概况

| 组别 | 对手 | 简要评价 |
|------|------|----------|
| {X}组 | {对手1} | ... |
| {X}组 | {对手2} | ... |
| {X}组 | {对手3} | ... |

分析该组的出线形势：谁是头号出线热门？该队处于什么位置？

```
query: "$0 2026 世界杯 小组赛 分组 出线形势"
query: "$0 2026 FIFA World Cup group draw analysis"
```

#### 二、大名单概况

基于已公布的初选名单或预选赛主力阵容。

```
# 第一级：中文
query: "$0 2026 世界杯 初选名单 大名单"
# 未命中 → 第二级

# 第二级：英文
query: "$0 2026 FIFA World Cup preliminary squad"
# 未命中 → 第三级

# 第三级：近期赛事阵容
query: "$0 2026 阵容 预选赛"
# 未命中 → 标"大名单尚未公布"
```

列出核心球员和可能的阵容框架（标注"初选名单/预选赛阵容"而非"确认首发"）。

#### 三、小组出线前景

基于 FIFA 排名、预选赛表现、阵容实力，分析该队的小组出线概率和可能的淘汰赛路径。

#### 四、核心球员扫描

挑出 3-5 名关键球员，简要介绍其在国家队的角色和俱乐部表现（复用 [references/player.md](references/player.md) 的球员信息表结构，但简化为每人 2-3 句）。

#### 五、世界杯历史底蕴

该队历届世界杯参赛经历和最佳成绩（简要版，结构参考 [references/historical.md](references/historical.md)）。若为首次参赛，说明晋级之路。

### 输出长度

目标 1000 字，底线 600 字。

## 出线等待变体 [E]

当路由判定球队已确认出线但下一轮淘汰赛对手尚未确定时启用。这是一个短暂但令球迷兴奋的阶段——出线已锁定，等待对手揭晓。

### 必选搜索

```
# 第一级：中文
query: "$0 2026 世界杯 出线 淘汰赛 对手"
query: "$0 2026 世界杯 晋级 16 强 对阵"
# 命中标准：有出线确认信息和潜在对手分析
# 未命中 → 第二级

# 第二级：英文
query: "$0 2026 FIFA World Cup knockout round opponent bracket"
# 未命中 → 标"对手待定"
```

### 输出结构

```
# {国旗emoji} $0 | 2026 世界杯出线确认 ✅
🏟️ 晋级阶段：{32 强 / 16 强 / 8 强 / ...} | 等待对手中

{一段话概述：出线的关键过程和球迷的期待}
```

#### 一、出线回顾

简要回顾小组赛的晋级之路：3 场比赛的关键节点，哪些表现确保了出线。~200 字。

#### 二、晋级路径表

| 阶段 | 对手 | 比分 | 状态 |
|------|------|------|------|
| 小组赛第1轮 | ... | ... | 已踢 |
| 小组赛第2轮 | ... | ... | 已踢 |
| 小组赛第3轮 | ... | ... | 已踢 |
| **下一轮（待定）** | **待确定** | — | 等待中 |
| 后续轮次 | 待定 | — | 待踢 |

#### 三、潜在对手分析

列出所有可能的下一轮对手（基于其他组的结果），每个对手 2-3 句话：核心球员、战术特点、对阵关键。~300 字。

#### 四、淘汰赛展望

基于球队状态和分组形势，分析本届淘汰赛的预期目标和关键看点。~150 字。

### 输出长度

目标 800 字，底线 500 字。
