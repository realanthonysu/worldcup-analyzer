# 教练模式

教练执教的世界队参加 2026 世界杯时启用。独立于球队/球员模式，有自己的输出结构。

## 必选搜索

教练履历和胜率数据（三级降级）：

```
# 第一级：中文
query: "$0 执教生涯 国家队 战绩 胜率"
query: "$0 国家队主教练 执教成绩 2026"
# 命中标准：有具体场次、胜平负数据
# 未命中 → 第二级

# 第二级：英文
query: "$0 national team coaching record win rate"
query: "$0 manager career stats national team"
# 命中标准：有具体 W-D-L 数据或胜率
# 未命中 → 第三级

# 第三级：综合搜索
query: "$0 coach profile career history"
# 未命中 → 标"执教数据待确认"
```

世界杯执教履历（两级降级）：

```
# 第一级：中文
query: "$0 世界杯 执教 经历 成绩"
# 未命中 → 第二级

# 第二级：英文
query: "$0 World Cup coaching history"
# 未命中 → 标"首次执教世界杯"或"待确认"
```

战术风格 / 主要成就（LLM 知识为主，搜索验证）：

```
query: "$0 战术风格 执教特点 tactical style"
```

## 输出结构

```
# 🎯 $0 | 2026 世界杯教练档案
🏟️ 执教球队：{国家队名} | 上任时间：{日期} | 年龄：{N} 岁

{一段话概述：该教练在国家队层面的定位和本届世界杯的意义}
```

### 一、执教履历

| 执教球队 | 任期 | 场次 | 胜-平-负 | 胜率 | 主要成绩 |
|----------|------|------|----------|------|----------|
| {国家队A} | 20XX-20XX | 120 | 78-22-20 | 65% | 20XX 世界杯八强 |
| {国家队B（现任）} | 20XX-至今 | 45 | 30-10-5 | 67% | — |

数据必须来自搜索结果。无数据的列标"待确认"。

### 二、世界杯执教记录

历届世界杯执教成绩（如有）：

| 年份 | 球队 | 最终成绩 | 关键场次 | 备注 |
|------|------|----------|----------|------|
| 2018 | 法国 | 冠军 | 决赛 4-2 克罗地亚 | 球员+教练双冠第三人 |

若无世界杯执教经历，写"首次以主教练身份参加世界杯"。

### 三、战术风格

{2-3 句话概括执教理念、常用阵型、进攻/防守偏好}

覆盖以下维度（有料则写，没料跳过）：

- **阵型偏好**：常用阵型及变阵习惯
- **进攻风格**：控球主导 / 快速反击 / 边路突破
- **防守理念**：高位逼抢 / 低位防守 / 中场绞杀
- **换人策略**：比赛中的调整节奏和偏好

### 四、本届世界杯展望

基于该队阵容实力、分组情况、教练过往大赛表现，分析本届世界杯预期目标。

```
query: "{国家队名} 2026 世界杯 分组 出线形势"
```

### 五、执教轶事与典故

1-3 条关于该教练的有趣故事或经典语录。来源策略同典故花絮（LLM 知识为主，搜索验证）。

## 输出长度

目标 800 字，底线 500 字。

## 注意事项

- 教练模式是独立模式，**不叠加**球队五件套或球员聚焦段
- 胜率/战绩等数字必须来自 web search，无把握时标"待确认"
- 数字不写范围（不写"65%-70%"，选最权威源写具体数字）
- 若教练同时具有球员身份（如齐达内曾执教），仍按教练模式处理，不进入球员模式
- 关键数据后附来源 URL（FIFA / Wikipedia / Transfermarkt）

## 世界杯复盘变体

当路由阶段一判定赛事已完全结束**且输入为教练名（通过教练验证）**时，使用以下结构替代标准教练五段。视角从"赛前展望"切换为"整届世界杯教练旅程复盘"——聚焦该教练在本届世界杯的执教旅程、关键决策和高光时刻。

### 必选搜索

```
# 第一级：中文
query: "$0 2026 世界杯 执教 总结 成绩"
query: "{国家队名} 2026 世界杯 全部比赛 战绩"
# 命中标准：有完整赛事战绩和教练评价
# 未命中 → 第二级

# 第二级：英文
query: "$0 2026 FIFA World Cup coaching campaign summary"
# 未命中 → 标"基于已有比赛数据汇总"
```

### 输出结构

```
# 🎯 $0 | 2026 美加墨世界杯执教复盘
🏟️ 执教球队：{国家队名} | 最终成绩：{名次} | 年龄：{N} 岁

{一段话概述：该教练在本届世界杯的执教旅程——从备战到赛场上的关键决策和结果}
```

#### 一、本届执教战绩

| 阶段 | 日期 | 对手 | 比分 | 结果 | 战术要点 |
|------|------|------|------|------|----------|
| 小组赛第1轮 | ... | ... | ... | 胜/平/负 | ... |
| 小组赛第2轮 | ... | ... | ... | ... | ... |
| 小组赛第3轮 | ... | ... | ... | ... | ... |
| 1/16 决赛 | ... | ... | ... | ... | ... |
| ... | ... | ... | ... | 最终名次 | ... |

#### 二、关键比赛复盘

从全部比赛中选最有代表性的 1-2 场，从**教练决策视角**复盘：阵型选择、换人时机、战术调整。篇幅压缩到每场 200 字左右。

#### 三、战术演变

该教练在本届赛事中的战术变化轨迹：小组赛阶段 vs 淘汰赛阶段的战术差异，关键比赛的战术调整是否奏效。

#### 四、本届世界杯的执教旅程与意义

该教练在本届世界杯经历了什么？是历史性突破、卫冕成功、还是遗憾出局？有哪些关键决策留在了球迷记忆中？用一段话回顾这届世界杯在其执教生涯中的意义。若教练赛后宣布离任，补充离任背景。

### 输出长度

目标 800 字，底线 500 字。
