# 赛后模式「五件套」

对最后一场已踢完的比赛进行复盘。

## 必选搜索

先执行以下搜索，获取比赛实时数据（严格三级降级，比分/进球/红牌不允许推测）：

```
# 第一级：中文精准
query: "{队A} vs {队B} 2026 世界杯 比分 进球 阵容"
query: "{队A} vs {队B} 2026 世界杯 进球 红牌 换人 事件"
# 命中标准：有具体比分和进球者
# 未命中 → 第二级

# 第二级：英文精准
query: "{team A} vs {team B} 2026 FIFA World Cup score goals lineup"
# 命中标准：BBC/FIFA 等有比赛报道
# 未命中 → 第三级

# 第三级：英文宽泛
query: "{team A} vs {team B} 2026 World Cup result"
# 未命中 → 直接告知用户"无法获取比分数据，请稍后重试"，不做任何兜底输出
```

数据以搜索结果为准，不使用 LLM 知识补充比分/进球者/红牌等具体事件。

## 一、比赛回顾

```
# {队A} {比分} {队B} | 2026 世界杯 {阶段}
📅 {日期} | {场地}

{一段话概述比赛走势和结果}
```

## 二、关键事件链

按时间线列出决定比赛走向的事件。时间列必须标注比赛阶段：

| 时间 | 阶段 | 事件 | 影响 |
|------|------|------|------|
| 23' | 上半场 | 进球（姆巴佩） | 打破僵局 |
| 45'+3' | 补时 | 黄牌 | 下轮停赛风险 |
| 58' | 下半场 | 换人（下 A 上 B） | 战术调整 |
| 72' | 下半场 | 红牌 | 人数劣势 |
| 90'+6' | 补时 | 绝平进球 | 拖入加时 |
| 105' | 加时上 | 进球 | 再次领先 |
| 120'+2' | 加时补时 | 绝杀 | 锁定胜局 |
| 点球 | 点球大战 | 点球 4-3 | 晋级 |

阶段标注规则：
- 常规时间：上半场 / 下半场 / 补时（写具体分钟如 45'+3'）
- 加时赛：加时上 / 加时下 / 加时补时
- 点球：直接写"点球"，结果写比分格式（如 4-3）

## 三、战术执行评估

对照赛前预期，评估：
- 阵型是否如预期？有无变阵？
- 关键对位结果如何？
- 哪个战术决策最影响比赛走向？

若本次会话中曾生成赛前分析 → 直接对比赛前预期。
若无赛前分析 → 基于两队 FIFA 排名、阵容实力、赛前舆论做简要预期概述（标注"基于赛前公开信息"），再进行对比评估。

```
# 第一级：中文
query: "{队A} 2026 世界杯 球员表现 评分"
query: "{队B} 2026 世界杯 球员表现 评分"
# 命中标准：有具体球员评分或表现描述
# 未命中 → 第二级

# 第二级：英文
query: "{team A} 2026 World Cup player ratings"
query: "{team B} 2026 World Cup player ratings"
# 未命中 → 基于比赛事件链中的信息做简要评价，标"无评分数据"
```

## 四、表现亮点与问题

- **亮点**：表现最好的 2-3 名球员 + 具体表现
- **问题**：暴露的弱点 + 可能的改进方向

## 五、后续展望

- 出局/晋级形势分析
- 下一场对手预测（如已确定）
- 该队本届世界杯的前景判断

注意：若为决赛（无下一场），改为"本届世界杯总结"。若球队已淘汰，写"出局回顾"而非"下一场对手预测"。

---

## 复合模式指引 [B]

当路由判定球队已踢过比赛且还有下一场时，输出"复盘 + 前瞻"两段式复合结构。**不使用第五节"后续展望"**（由下半段前瞻覆盖）。

### 上半段：最近一场赛后复盘（~800 字）

复用本文件第一至四节（比赛回顾 / 关键事件链 / 战术执行评估 / 表现亮点与问题），跳过第五节。

搜索指令、降级链、事件链阶段标注规则均与标准五件套一致。

### 下半段：下一场前瞻（~800 字）

复用 [references/pre-match.md](references/pre-match.md) 的精简版：

- 赛程概览（全部赛程表，标注已踢/本轮/待踢）
- 双方预计首发（阵型对比表 + 门将焦点）
- 战术推演（**基于上一场表现的针对性分析**，非泛泛而谈）
- 世界杯 H2H（与下一场对手的历史交锋）
- 典故与花絮（有料则写，没料跳过）

> 下半段前瞻省略"赛事概览"标题头（上半段已有比赛信息），直接从赛程表开始。

### 输出长度

两段合计目标 1500-1800 字，底线 1000 字。复盘和前瞻各占约一半，避免上重下轻。

## 赛事复盘变体 [C]

当路由判定球队已在赛事中被淘汰（小组赛出局或淘汰赛落败）时启用。**不等世界杯整体结束**——对该队而言赛事已结束。

与"世界杯复盘变体"的区别：世界杯复盘变体仅在赛事整体结束后（> 07-19）触发；本变体在赛事进行中球队被淘汰时即触发。两者结构相似，但本变体增加"出局归因"维度。

### 必选搜索

```
# 第一级：中文
query: "$0 2026 世界杯 战绩 出局 淘汰"
query: "$0 2026 世界杯 全部比赛 成绩"
# 命中标准：有完整战绩和淘汰信息
# 未命中 → 第二级

# 第二级：英文
query: "$0 2026 FIFA World Cup campaign eliminated"
# 未命中 → 标"基于已有比赛数据汇总"
```

### 输出结构

```
# {国旗emoji} $0 | 2026 世界杯赛事复盘
📅 最终成绩：{小组赛出局 / 止步 32 强 / 止步 16 强 / ...} | {最终名次}

{一段话概述：该队在本届世界杯的整体表现和出局原因}
```

#### 一、完整战绩回顾

| 阶段 | 日期 | 对手 | 比分 | 结果 |
|------|------|------|------|------|
| 小组赛第1轮 | ... | ... | ... | 胜/平/负 |
| ... | ... | ... | ... | 最终结果 |

#### 二、关键比赛复盘

从全部比赛中选最有代表性的 1-2 场，做简要复盘。淘汰赛落败时可更深入（更多比赛可回顾，~250 字/场）；小组赛出局相对精简（~200 字/场）。

#### 三、核心球员表现

列出本届赛事表现最突出的 3-5 名球员，附进球/助攻/关键数据。

#### 四、出局归因

从战术、人员、伤病、运气等维度做简要归因分析（2-3 句话）。淘汰赛落败的归因可以更深入（涉及具体比赛决策）；小组赛出局侧重整体实力/分组难度。

#### 五、本届总结

一段话定位该队在本届世界杯的表现——是遗憾出局、实力使然、还是虽败犹荣？

### 球员模式叠加

若为球员模式，附加球员聚焦段（复用 [references/player.md](references/player.md)），"本届展望"改为"本届表现回顾"。

### 输出长度

目标 1000 字，底线 600 字。淘汰赛落败可比小组赛出局多 100-200 字。

## 小组收官变体 [F]

当路由判定小组赛全部踢完但出线结果尚未确定时启用（含第三名排名待定场景）。

### 必选搜索

```
# 第一级：中文
query: "$0 2026 世界杯 积分榜 出线 排名"
query: "{组名} 2026 世界杯 积分 第三名 出线"
# 命中标准：有完整积分表和跨组第三名对比
# 未命中 → 第二级

# 第二级：英文
query: "$0 2026 FIFA World Cup group standings qualification"
query: "2026 World Cup best third place teams standings"
# 未命中 → 标"出线形势待确认"
```

### 输出结构

#### 上半段：最后一场赛后复盘（~500 字）

复用标准五件套第一至四节，篇幅压缩。

#### 下半段：出线形势分析（~500 字）

| 内容 | 说明 |
|------|------|
| 小组积分榜 | 完整 4 队积分表（积分/净胜球/进球数） |
| 同组另一场比赛结果 | 影响出线形势的关键信息 |
| 第三名跨组对比 | 与其他组第三名的积分/净胜球对比（2026 规则：8 个最佳第三名晋级 32 强） |
| 出线路径分析 | 各种可能结果下的走向——出线后的潜在对手 vs 淘汰后的总结 |

> 2026 世界杯出线规则：12 组×4 队，小组前 2 名直接晋级 32 强 + 8 个成绩最佳小组第三。
> 因此"小组第三"仍有出线可能，不可直接判定出局。

### 输出长度

目标 1000 字，底线 500 字。

---

## 世界杯复盘变体

当路由阶段一判定赛事已完全结束时，使用以下结构替代五件套。视角从"刚踢完一场"切换为"整届世界杯旅程回顾"——聚焦该队在本届世界杯的旅程、表现和高光时刻。

### 必选搜索

```
# 第一级：中文
query: "$0 2026 世界杯 战绩 总结 回顾"
query: "$0 2026 世界杯 全部比赛 成绩"
# 命中标准：有完整赛事战绩
# 未命中 → 第二级

# 第二级：英文
query: "$0 2026 FIFA World Cup campaign summary"
# 命中标准：BBC/FIFA 等有赛事总结报道
# 未命中 → 标"基于已有比赛数据汇总"
```

### 输出结构

```
# {国旗emoji} $0 | 2026 美加墨世界杯复盘
📅 赛事日期：2026-06-11 ~ 2026-07-19 | 最终名次：{名次}

{一段话概述：该队在本届世界杯的旅程——从期待到赛场上的高光与遗憾}
```

#### 一、完整战绩回顾

| 阶段 | 日期 | 对手 | 比分 | 结果 |
|------|------|------|------|------|
| 小组赛第1轮 | ... | ... | ... | 胜/平/负 |
| 小组赛第2轮 | ... | ... | ... | ... |
| 小组赛第3轮 | ... | ... | ... | ... |
| 1/16 决赛 | ... | ... | ... | ... |
| ... | ... | ... | ... | 最终名次 |

#### 二、关键比赛复盘

从全部比赛中选最有代表性的 1-2 场（不一定是最后一场），做简要复盘：比分走势、关键时刻、战术亮点。复用赛后五件套的"事件链"和"战术评估"结构，但篇幅压缩到每场 200 字左右。

#### 三、核心球员表现

列出本届赛事表现最突出的 3-5 名球员，附进球/助攻/关键数据。可复用 [references/player.md](references/player.md) 的信息表结构，但简化为简要版。

#### 四、本届世界杯的旅程与意义

该队在本届世界杯经历了什么？是历史性突破、卫冕成功、还是遗憾出局？有哪些高光时刻留在了球迷记忆中？用一段话回顾这届世界杯在该队足球史上的意义。

### 球员模式叠加

若为球员模式，在世界杯复盘基础上附加球员聚焦段（复用 [references/player.md](references/player.md)），但"本届展望"改为"本届表现回顾"——回顾该球员在本届世界杯的旅程、数据和高光时刻。

### 输出长度

目标 1000 字，底线 600 字。
