# 赛后模式「五件套」

对最后一场已踢完的比赛进行复盘。

## 必选搜索

先执行以下搜索，获取比赛实时数据（严格三级降级，比分/进球/红牌不允许推测）：

```
# 第一级：中文精准
query: "{队A} vs {队B} 2026 世界杯 比分 进球 阵容"
query: "{队A} vs {队B} 2026 世界杯 进球 红牌 换人 事件"
# 命中标准：有具体比分和进球者
# 未命中 → 第二级

# 第二级：英文精准
query: "{team A} vs {team B} 2026 FIFA World Cup score goals lineup"
# 命中标准：BBC/FIFA 等有比赛报道
# 未命中 → 第三级

# 第三级：英文宽泛
query: "{team A} vs {team B} 2026 World Cup result"
# 未命中 → 直接告知用户"无法获取比分数据，请稍后重试"，不做任何兜底输出
```

数据以搜索结果为准，不使用 LLM 知识补充比分/进球者/红牌等具体事件。

## 一、比赛回顾

```
# {队A} {比分} {队B} | 2026 世界杯 {阶段}
📅 {日期} | {场地}

{一段话概述比赛走势和结果}
```

## 二、关键事件链

按时间线列出决定比赛走向的事件。时间列必须标注比赛阶段：

| 时间 | 阶段 | 事件 | 影响 |
|------|------|------|------|
| 23' | 上半场 | 进球（姆巴佩） | 打破僵局 |
| 45'+3' | 补时 | 黄牌 | 下轮停赛风险 |
| 58' | 下半场 | 换人（下 A 上 B） | 战术调整 |
| 72' | 下半场 | 红牌 | 人数劣势 |
| 90'+6' | 补时 | 绝平进球 | 拖入加时 |
| 105' | 加时上 | 进球 | 再次领先 |
| 120'+2' | 加时补时 | 绝杀 | 锁定胜局 |
| 点球 | 点球大战 | 点球 4-3 | 晋级 |

阶段标注规则：
- 常规时间：上半场 / 下半场 / 补时（写具体分钟如 45'+3'）
- 加时赛：加时上 / 加时下 / 加时补时
- 点球：直接写"点球"，结果写比分格式（如 4-3）

## 三、战术执行评估

对照赛前预期，评估：
- 阵型是否如预期？有无变阵？
- 关键对位结果如何？
- 哪个战术决策最影响比赛走向？

若本次会话中曾生成赛前分析 → 直接对比赛前预期。
若无赛前分析 → 基于两队 FIFA 排名、阵容实力、赛前舆论做简要预期概述（标注"基于赛前公开信息"），再进行对比评估。

```
# 第一级：中文
query: "{队A} 2026 世界杯 球员表现 评分"
query: "{队B} 2026 世界杯 球员表现 评分"
# 命中标准：有具体球员评分或表现描述
# 未命中 → 第二级

# 第二级：英文
query: "{team A} 2026 World Cup player ratings"
query: "{team B} 2026 World Cup player ratings"
# 未命中 → 基于比赛事件链中的信息做简要评价，标"无评分数据"
```

## 四、表现亮点与问题

- **亮点**：表现最好的 2-3 名球员 + 具体表现
- **问题**：暴露的弱点 + 可能的改进方向

## 五、后续展望

- 出局/晋级形势分析
- 下一场对手预测（如已确定）
- 该队本届世界杯的前景判断

注意：若为决赛（无下一场），改为"本届世界杯总结"。若球队已淘汰，写"出局回顾"而非"下一场对手预测"。

---

## 赛事总结变体

当路由阶段零判定赛事已完全结束时，使用以下结构替代五件套。视角从"刚踢完一场"切换为"整届赛事回顾"。

### 必选搜索

```
# 第一级：中文
query: "$0 2026 世界杯 战绩 总结 回顾"
query: "$0 2026 世界杯 全部比赛 成绩"
# 命中标准：有完整赛事战绩
# 未命中 → 第二级

# 第二级：英文
query: "$0 2026 FIFA World Cup campaign summary"
# 命中标准：BBC/FIFA 等有赛事总结报道
# 未命中 → 标"基于已有比赛数据汇总"
```

### 输出结构

```
# {国旗emoji} $0 | 2026 世界杯赛事总结
📅 赛事日期：2026-06-11 ~ 2026-07-19 | 最终名次：{名次}

{一段话概述：该队在本届世界杯的整体表现和历史定位}
```

#### 一、完整战绩回顾

| 阶段 | 日期 | 对手 | 比分 | 结果 |
|------|------|------|------|------|
| 小组赛第1轮 | ... | ... | ... | 胜/平/负 |
| 小组赛第2轮 | ... | ... | ... | ... |
| 小组赛第3轮 | ... | ... | ... | ... |
| 1/16 决赛 | ... | ... | ... | ... |
| ... | ... | ... | ... | 最终名次 |

#### 二、关键比赛复盘

从全部比赛中选最有代表性的 1-2 场（不一定是最后一场），做简要复盘：比分走势、关键时刻、战术亮点。复用赛后五件套的"事件链"和"战术评估"结构，但篇幅压缩到每场 200 字左右。

#### 三、核心球员表现

列出本届赛事表现最突出的 3-5 名球员，附进球/助攻/关键数据。可复用 [references/player.md](references/player.md) 的信息表结构，但简化为简要版。

#### 四、本届世界杯的历史意义

该队在本届世界杯创造了什么？是历史性突破、卫冕成功、还是遗憾出局？用一段话定位这届世界杯在该队足球史上的意义。

### 球员模式叠加

若为球员模式，在赛事总结基础上附加球员聚焦段（复用 [references/player.md](references/player.md)），但"本届展望"改为"本届表现回顾"——从预测变为复盘。

### 输出长度

目标 1000 字，底线 600 字。
