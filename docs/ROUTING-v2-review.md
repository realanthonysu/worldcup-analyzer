### 赛事进行中：搜索验证 + 路由表 v2

#### 搜索验证（扩展）

相比 v1 只查赛程，v2 需要同时获取三类信息：

```
query: "$0 2026 世界杯 赛程 比分 结果 小组赛"
query: "$0 2026 FIFA World Cup schedule results group"
query: "$0 2026 世界杯 积分 排名 出线"
```

从搜索结果中提取：
- **赛程表**：全部场次（已踢/未踢/进行中）
- **已踢比赛结果**：比分、进球者、关键事件
- **出线状态**：确认出线 / 确认淘汰 / 未定

#### 路由决策树

```
赛事进行中
  │
  ├─ Step 1: 是否有比赛正在进行中？
  │     └─ 是 → 提示用户稍后再查询 → 终止
  │
  ├─ Step 2: 是否存在未踢的比赛？
  │     │
  │     ├─ 是（还有下一场）
  │     │     │
  │     │     ├─ Step 2a: 是否存在已踢完的比赛？
  │     │     │     │
  │     │     │     ├─ 否（一场都没踢）
  │     │     │     │     → [A] 赛前分析（首战前瞻 + 全部赛程表）
  │     │     │     │
  │     │     │     └─ 是（踢过比赛了）
  │     │     │           → [B] 最近一场赛后复盘 + 下一场前瞻
  │     │     │
  │     │     └─ 下一场是淘汰赛？
  │     │           → 同 [A] 或 [B]，但前瞻部分用淘汰赛变体（晋级路径表）
  │     │
  │     └─ 否（全部踢完了，没有下一场）
  │           │
  │           ├─ Step 3: 出线状态？
  │           │     │
  │           │     ├─ 确认淘汰（小组赛出局 / 淘汰赛落败）
  │           │     │     → [C] 赛事复盘（该队本届总结）
  │           │     │
  │           │     ├─ 确认出线，等待下一轮淘汰赛
  │           │     │     │
  │           │     │     ├─ 下一轮对手已确定
  │           │     │     │     → [D] 淘汰赛赛前（晋级路径 + 对手前瞻）
  │           │     │     │
  │           │     │     └─ 下一轮对手未确定
  │           │     │           → [E] 出线确认 + 等待对手
  │           │     │
  │           │     └─ 出线未定（小组第三排名待定）
  │           │           → [F] 小组收官 + 出线形势分析
  │           │
  │           └─（无其他情况）
  │
  └─ 搜索失败 → 输出"无法获取赛程/比分数据，请稍后重试" → 终止
       ⚠️ 搜索失败 ≠ 未参赛，不可进入历史模式
```

### 输出模式详解

#### [A] 赛前分析（首战前瞻）

**触发**：赛事进行中，球队一场都没踢。

| 内容 | 说明 |
|------|------|
| 赛事概览 | 球队所处小组、首战对手、战略意义 |
| 全部赛程表 | 3 场小组赛，状态全部为"待踢" |
| 双方预计首发 | 阵型对比表 + 门将焦点 |
| 战术推演 | 控球/反击、关键对位、X 因素 |
| 世界杯 H2H | 历史交锋表 |
| 典故与花絮 | 故事性和趣味 |

模板：`pre-match.md` §小组赛（不变）

---

#### [B] 最近一场赛后复盘 + 下一场前瞻（复合模式）

**触发**：赛事进行中，球队已踢过比赛且还有下一场。

**输出结构（两段式）**：

**上半段：最近一场赛后复盘**（~800 字）

| 内容 | 说明 |
|------|------|
| 比赛回顾 | 比分、一段话概述 |
| 关键事件链 | 时间线表格（含阶段标注：上半场/补时/加时/点球） |
| 战术执行评估 | 阵型/对位/关键决策 |
| 表现亮点与问题 | 最佳球员 + 暴露的弱点 |

**下半段：下一场前瞻**（~800 字）

| 内容 | 说明 |
|------|------|
| 赛程概览 | 全部赛程表（标注已踢/本轮/待踢） |
| 双方预计首发 | 阵型对比表 + 门将焦点 |
| 战术推演 | 基于上一场表现的针对性分析 |
| 世界杯 H2H | 与下一场对手的历史交锋 |
| 典故与花絮 | 故事性和趣味 |

模板：`post-match.md` §一~四（上半段）+ `pre-match.md` §一~五（下半段，精简版）

> 字数目标：整体 1500-1800 字，底线 1000 字。复盘和前瞻各占约一半，
> 避免上重下轻或反之。

---

#### [C] 赛事复盘（该队已被淘汰）

**触发**：赛事进行中，球队已确认淘汰（小组赛出局或淘汰赛落败）。

> 不等世界杯整体结束。对该队而言赛事结束了。

| 内容 | 说明 |
|------|------|
| 完整战绩回顾 | 全部已踢场次战绩表 |
| 关键比赛复盘 | 选 1-2 场代表作，教练/战术视角，每场 ~200 字 |
| 核心球员表现 | 3-5 名突出球员 + 进球/助攻/关键数据 |
| 出局原因分析 | 战术/人员/运气等维度的简要归因 |
| 本届总结 | 一段话定位该队在本届世界杯的表现 |

模板：`post-match.md` §赛事总结变体（复用，但"历史意义"改为"出局归因"）

> 球员模式叠加：附加球员聚焦段，"本届展望"改为"本届表现回顾"。

---

#### [D] 淘汰赛赛前

**触发**：赛事进行中，球队已出线且下一轮对手已确定。

| 内容 | 说明 |
|------|------|
| 赛事概览 | 所处淘汰赛阶段 + 晋级路径表 |
| 双方预计首发 | 阵型对比表 + 门将焦点 |
| 战术推演 | 淘汰赛特有的谨慎策略分析 |
| 世界杯 H2H | 历史交锋 |
| 典故与花絮 | 故事性和趣味 |

模板：`pre-match.md` §淘汰赛变体（不变）

> 若 [B] 的"下一场"恰好是淘汰赛，下半段用此模板替代小组赛版。

---

#### [E] 出线确认 + 等待对手

**触发**：赛事进行中，球队已确认出线但下一轮对手尚未确定。

| 内容 | 说明 |
|------|------|
| 出线确认 | 确认出线的依据（积分/排名/结果） |
| 最近一场赛后复盘 | 同 [B] 上半段（若是从小组赛最后一场出线） |
| 潜在对手分析 | 列出可能的对手及各自特点（简要） |
| 晋级路径表 | 标注已踢/待定 |

> 字数目标：800 字，底线 500 字。

---

#### [F] 小组收官 + 出线形势分析

**触发**：赛事进行中，小组赛全部踢完，出线结果尚未确定。

| 内容 | 说明 |
|------|------|
| 最后一场赛后复盘 | 同 [B] 上半段 |
| 小组积分榜 | 完整积分表（4 队 × 积分/净胜球/进球） |
| 同组另一场比赛结果 | 影响出线形势的关键信息 |
| 第三名跨组对比 | 与其他组第三名的积分/净胜球对比（8 个最佳第三名晋级） |
| 出线路径分析 | 各种可能结果下的走向（出线 vs 淘汰） |

> 2026 规则：12 组 × 4 队，前 2 名直接晋级 32 强 + 8 个最佳第三名。
> 因此小组第三仍有出线可能，不可直接判定出局。

> 字数目标：1000 字，底线 500 字。

### 模式总览表

| 编号 | 模式 | 触发条件 | 核心输出 | 字数目标 |
|------|------|----------|----------|----------|
| A | 赛前·首战 | 赛事进行中 + 0 场已踢 | 前瞻 + 赛程表 | 1500/800 |
| B | 复盘+前瞻（复合） | 赛事进行中 + ≥1 场已踢 + 有下一场 | 最近一场复盘 + 下一场前瞻 | 1500/1000 |
| C | 赛事复盘 | 赛事进行中 + 已淘汰 | 战绩/关键比赛/归因/总结 | 1000/600 |
| D | 赛前·淘汰赛 | 赛事进行中 + 已出线 + 对手已定 | 晋级路径 + 前瞻 | 1500/800 |
| E | 出线等待 | 赛事进行中 + 已出线 + 对手未定 | 出线确认 + 潜在对手 | 800/500 |
| F | 小组收官 | 赛事进行中 + 踢完 + 出线未定 | 复盘 + 积分/跨组对比 | 1000/500 |

加上不变的外围模式：

| 编号 | 模式 | 触发条件 | 字数目标 |
|------|------|----------|----------|
| — | 赛事前瞻 | 赛事未开始 + 确认参赛 | 1000/600 |
| — | 赛事总结 | 赛事已结束 | 1000/600 |
| — | 教练 | 教练验证通过 | 800/500 |
| — | 教练赛事总结 | 赛事已结束 + 教练 | 800/500 |
| — | 历史 | 确认未参赛 | 500/300 |

### 与 v1 路由的对比

| 场景 | v1 路由 | v2 路由 | 变化 |
|------|---------|---------|------|
| 小组赛第一场还没踢 | 赛前分析 | [A] 赛前分析 | 不变 |
| 踢完第一场，第二场还没踢 | 赛前分析（第二场） | **[B] 第一场复盘 + 第二场前瞻** | **新增复盘** |
| 踢完第二场，第三场还没踢 | 赛前分析（第三场） | **[B] 第二场复盘 + 第三场前瞻** | **新增复盘** |
| 小组赛全踢完，已出线 | 赛后（最后一场） | [D] 淘汰赛赛前（或 [E] 等待对手） | 更精准 |
| 小组赛全踢完，出线未定 | 小组收官+等待 | [F] 小组收官 + 出线形势分析 | 内容充实 |
| 小组赛全踢完，已淘汰 | 赛后（最后一场） | **[C] 赛事复盘** | **不等世界杯结束** |
| 淘汰赛即将踢 | 赛前·淘汰赛 | [D] 淘汰赛赛前（或 [B] 若前一场刚踢完） | 更精准 |
| 淘汰赛踢完，晋级 | 赛后 | **[B] 本轮复盘 + 下一轮前瞻** | **新增复盘+前瞻** |
| 淘汰赛踢完，淘汰 | 赛后 | **[C] 赛事复盘** | **不等世界杯结束** |
