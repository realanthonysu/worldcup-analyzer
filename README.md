# worldcup-analyzer

2026 美加墨世界杯深度分析 Agent Skill。为中文球迷设计，世界杯球迷赛事分析，不靠印象分析，靠结构分析。

## 使用

```
/worldcup-analyzer 法国          # 球队模式
/worldcup-analyzer 姆巴佩        # 球员模式（自动推断所属球队）
```

## 功能

通过 `/worldcup-analyzer` 斜杠命令触发，支持多种分析模式。

### 路由系统

整个路由是**两层过滤**结构：

**第一层：阶段零（按日期过滤）** — 进入任何分析之前，先拿当前日期和赛事配置做比较。日期在 6 月 11 日之前，先做参赛验证：确认参赛走赛事前瞻模式，确认未参赛走历史模式（含从未参赛的处理）；日期在 7 月 19 日之后，直接走赛事总结模式。只有日期落在赛事期间，才进入第二层。

**第二层：搜索验证 + 路由表（按赛程状态过滤）** — 先 web search 确认该队赛程。搜索失败直接报错；确认无赛程走历史模式；正常赛程进入路由表，按比赛状态分发到赛前、赛后、小组收官等模式。

**球员模式**是叠加层 — 无论路由到哪个模式，只要输入的是球员名，就在球队分析基础上追加球员聚焦段。

```
/worldcup-analyzer <名字:球队/球员>
  │
  ├─ 日期 < 06-11 ─→ 参赛验证
  │                    ├─ 确认参赛 ──→ 赛事前瞻（+ 球员？）
  │                    ├─ 确认未参赛 → 历史模式（有历史 / 从未参赛）
  │                    └─ 搜索失败 ──→ 报错
  │
  ├─ 日期 > 07-19 ──────→ 赛事总结（+ 球员？）
  │
  └─ 赛事进行中 ─→ 搜索验证
                      │
                      ├─ 搜索失败 ──→ 报错
                      ├─ 未参赛 ────→ 历史模式（+ 球员？）
                      └─ 正常赛程 ─→ 路由表
                                       ├─ 小组赛有未踢 ──→ 赛前·小组赛版
                                       ├─ 淘汰赛有未踢 ──→ 赛前·淘汰赛版
                                       ├─ 出线已确认 ────→ 赛后
                                       ├─ 第三名未定 ────→ 小组收官 + 等待
                                       └─ 比赛进行中 ────→ 提示稍后
```

### 模式一览

| 模式 | 在哪一层决定 | 判定依据 | 核心输出 |
|------|-------------|---------|---------|
| 赛事前瞻 | 第一层（日期 + 参赛验证） | 当前 < 06-11 且确认参赛 | 分组概况 / 大名单 / 出线前景 / 核心球员 / 历史底蕴 |
| 赛事总结 | 第一层（日期） | 当前 > 07-19 | 完整战绩 / 关键比赛 / 核心球员 / 历史意义 |
| 赛前（小组赛） | 第二层（赛程） | 小组赛有未踢 | 概览 / 首发 / 战术 / H2H / 典故 |
| 赛前（淘汰赛） | 第二层（赛程） | 淘汰赛有未踢 | 晋级路径 / 首发 / 战术 / H2H / 典故 |
| 赛后 | 第二层（赛程） | 出线结果已确认 | 回顾 / 事件链 / 战术 / 亮点 / 展望 |
| 小组收官+等待 | 第二层（赛程） | 踢完但第三名未定 | 赛后复盘 + 出线形势分析 |
| 历史（有世界杯经历） | 第一层或第二层 | 确认未参赛 + 有参赛历史 | 历届记录表 + 经典比赛回顾 + 履历总结 |
| 历史（从未参赛） | 第一层或第二层 | 确认未参赛 + 从未进过决赛圈 | 说明从未参赛 + 预选赛出局情况 |
| 球员 | 叠加层 | 输入含球员名 | 球队模式 + 球员聚焦段 |

## 安装

以下两种方式任选其一：

### 方式一：让 Agent 直接安装（推荐）

把本仓库链接发给 QoderWork / Qwen Code / Claude Code 等支持 Agent Skills 的助手：

```
请安装这个 Skill：https://github.com/realanthonysu/worldcup-analyzer
```

Agent 会自动将其克隆到技能目录并加载。

### 方式二：使用 npx skills 命令安装

```bash
npx skills add https://github.com/realanthonysu/worldcup-analyzer --skill worldcup-analyzer
```

安装完成后刷新 Agent（执行 `/skills` 确认列表中显示 `worldcup-analyzer`）。
