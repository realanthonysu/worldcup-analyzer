# 历史模式

球队未参加 2026 世界杯时启用。分两种情况处理。

## 必选搜索

先确认该队参赛历史（两级降级）：

```
# 第一级：中文
query: "$0 世界杯 历届成绩 参赛记录"
query: "$0 2026 世界杯 预选赛 出局"
# 命中标准：有具体年份和成绩
# 未命中 → 第二级

# 第二级：英文
query: "$0 World Cup history results appearances"
# 未命中 → 使用 Wikipedia 作为最终兜底，标注来源
```

## 情况 A：从未参加过世界杯

直接回答"该队从未进入过世界杯决赛圈"，简要说明原因（预选赛出局等）。

**注意**：不要为了"显得有内容"而编造历史。

## 情况 B：曾经参加过但本届未入围

### 1. 历届参赛记录表

| 年份 | 成绩 | 关键事件 |
|------|------|----------|
| 2006 | 小组赛出局 | ... |
| 2010 | 16 强 | ... |

```
# 第一级：中文
query: "$0 世界杯 经典比赛 传奇时刻 历史"
# 命中标准：有具体比赛描述
# 未命中 → 第二级

# 第二级：英文
query: "$0 World Cup classic match history legendary"
# 未命中 → LLM 知识兜底，标"基于通用足球史料，未实时验证"
```

### 2. 该队世界杯最经典的一场比赛回顾

挑选一场代表作，描述：
- 对手与比分
- 关键进球 / 红牌 / 逆转
- 这场比赛的历史意义
- 与该队足球文化的关联

### 3. 该队整体世界杯履历总结

- 累计参赛届数
- 最佳成绩（如"四强"、"八强"）
- 球队的世界杯 DNA（一句话总结风格）
- 当家球星代表

## 输出长度

目标 500 字，底线 300 字。比赛前/赛后模式短，因为数据维度更少。
