# 球员聚焦段

在球队模式（赛前/赛后/历史任一）基础上，附加球员专属分析。

## 附加搜索

按降级链执行（两级降级）：

```
# 第一级：中文
query: "$0 2026 世界杯 数据 表现"
query: "$0 世界杯 生涯 历史"
query: "$0 2026 俱乐部 现效力 赛季数据"
# 命中标准：有具体出场数、进球数、俱乐部信息
# 未命中 → 第二级

# 第二级：英文
query: "$0 2026 FIFA World Cup stats performance"
query: "$0 2026 club current team season stats"
# 未命中 → 标"待官方确认"
```

## 附加输出

```
## 球员聚焦：$0

| 维度 | 内容 |
|------|------|
| 位置   | |
| 俱乐部 | |
| 国家队生涯 | {X} 场 {Y} 球 |
| 世界杯履历 | 参加过 {N} 届，最佳成绩 {成绩} |
| 本届角色 | 核心/主力/轮换 |

### 技术特点
{2-3 句话描述球员的踢球风格和关键能力}

### 位置关键数据

根据球员位置选择对应维度（有料则写，无数据跳过）：

| 位置 | 关键数据维度 |
|------|-------------|
| 前锋 | 进球效率（X 场 Y 球）、射门转化率、关键进球、本届进球/助攻 |
| 中场 | 传球成功率、创造机会数、控球覆盖范围、关键传球 |
| 后卫 | 拦截次数、解围数、防守成功率、空中对抗胜率 |
| 门将 | 扑救率、零封场次、出击成功率、本届失球数 |

### 本届展望
**上下文切换**：当球队已被淘汰或世界杯已结束时，本节标题改为「本届表现回顾」，内容从预测转为回顾（球员本届表现总结、关键数据、亮点与不足）。

{该球员在本届世界杯的预期表现和关键看点}
```

## 注意事项

- 球队五件套**不**可省略（球员模式 = 球队 + 球员）
- 球员聚焦段目标 300 字，底线 200 字
- 球员数据**必选 web search**：国家队 X 场 Y 球、世界杯履历、俱乐部本赛季数据均需验证
- 国家队生涯"X 场 Y 球"等数字无把握时改为"约 X 场 Y 球"或留空标注"待官方确认"
- 数字不要含糊（不写"55-56 球之间"——选最权威源写具体数字）
- 关键数据后附来源 URL（FIFA / Wikipedia / Transfermarkt / BBC Sport）
- 无世界杯履历时写"首次参加世界杯"而非"暂无数据"
