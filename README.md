# worldcup-analyzer

2026 美加墨世界杯深度分析 Agent Skill。为中文球迷设计，世界杯球迷赛事分析，不靠印象分析，靠结构分析。

## 使用

```
/worldcup-analyzer 法国          # 球队模式
/worldcup-analyzer 姆巴佩        # 球员模式（自动推断所属球队）
/worldcup-analyzer 曼联          # ❌ 拒收（俱乐部，非国家队）
/worldcup-analyzer 齐达内        # ❌ 拒收（已退役球员）
```

## 功能

通过 `/worldcup-analyzer` 斜杠命令触发，支持多种分析模式。

### 路由系统

整个路由是**三层过滤**结构：

**第一层：输入验证（防护门控）** — 拦截所有不属于世界杯分析范畴的输入。俱乐部球队（如曼联）、非足球实体（如卡车）、女足国家队、已不存在的国家队（如南斯拉夫）、已退役球员（如齐达内）、已故球员（如马拉多纳）都会收到友好提示后终止。只有确认为国家队、现役球员或足球教练的输入才能进入下一层。

**第二层：赛事窗口检查（按日期过滤）** — 拿当前日期和赛事配置做比较。日期在 6 月 11 日之前，先做参赛验证：确认参赛走赛事前瞻模式，确认未参赛走历史模式（含从未参赛的处理）；日期在 7 月 19 日之后，球队/球员走赛事总结模式，教练走教练赛事总结模式。只有日期落在赛事期间，才进入第三层。

**第三层：搜索验证 + 路由表 v2（先回顾、再前瞻）** — 先 web search 同时获取赛程、比分结果和积分排名。搜索失败直接报错；确认无赛程走历史模式；正常赛程按"先回顾、再前瞻"原则路由：踢过比赛先复盘最近一场再前瞻下一场，球队被淘汰直接进入赛事复盘（不等世界杯结束）。

**球员参赛验证** — 球员模式专属的第二道关卡。通过第一、二层后，检查球员是否退役、所属国家队是否参赛、是否在 26 人大名单中、大名单是否已公布。未通过则输出对应提示后终止。

**教练验证** — 教练模式专属的第二道关卡。5 级优先判断链：不再执教 → 执教参赛队 → 执教未参赛队 → 纯俱乐部教练 → 未执教。

**球员模式**是叠加层 — 无论路由到哪个模式，只要输入的是球员名且通过参赛验证，就在球队分析基础上追加球员聚焦段。**教练模式**是独立模式 — 有自己的输出结构，不叠加球队五件套。

```
/worldcup-analyzer <名字:球队/球员/教练>
  │
  ├─ 输入验证 ──── 俱乐部/非足球/女足/非现役等 → 友好提示 → 终止
  │                 ↓ 通过（国家队/现役球员/教练）
  │
  ├─ 日期 < 06-11 ─→ 参赛验证
  │                    ├─ 确认参赛 ──→ 赛事前瞻（+ 球员参赛验证 / 教练验证？）
  │                    ├─ 确认未参赛 → 历史模式（有历史 / 从未参赛）
  │                    └─ 搜索失败 ──→ 报错
  │
  ├─ 日期 > 07-19 ──→ 世界杯复盘
  │                    ├─ 球队/球员 ──→ 世界杯复盘（旅程/表现/高光）
  │                    └─ 教练 ──────→ 世界杯执教复盘
  │
  └─ 赛事进行中 ─→ 搜索验证（赛程 + 比分 + 积分）
                      │
                      ├─ 搜索失败 ──→ 报错
                      ├─ 未参赛 ────→ 历史模式
                      └─ 路由表 v2（+ 球员参赛验证 / 教练验证？）
                           ├─ 比赛进行中 ──────→ 提示稍后
                           ├─ 有未踢：0场已踢 ──→ [A] 赛前·首战
                           ├─ 有未踢：≥1场已踢 → [B] 复盘+前瞻（复合）
                           ├─ 无未踢：已淘汰 ──→ [C] 赛事复盘
                           ├─ 无未踢：已出线 ──→ [D]/[E] 淘汰赛赛前/等待
                           └─ 无未踢：出线未定 → [F] 小组收官

  球员参赛验证（仅球员输入）:
    ├─ 已退役 ──────────→ 退役提示 → 终止
    ├─ 国家队未参赛 ────→ 未参赛提示 → 终止
    ├─ 未入选大名单 ────→ 落选提示 → 终止
    ├─ 大名单未公布 ────→ 待确认提示 → 进入球员模式（标注待确认）
    └─ 确认在名单中 ────→ 进入球员模式

  教练验证（仅教练输入）:
    ├─ 不再执教 ──────────→ 提示 → 终止
    ├─ 执教参赛队 ────────→ 进入教练模式
    ├─ 执教未参赛队 ────→ 提示 + 简要履历 → 终止
    ├─ 纯俱乐部教练 ────→ 提示 → 终止
    └─ 未执教 ────────────→ 提示 + 简要履历 → 终止
```

### 模式一览

| 模式 | 在哪一层决定 | 判定依据 | 核心输出 |
|------|-------------|---------|---------|
| 输入拒收 | 第一层（输入验证） | 俱乐部/非足球/女足/已解体/退役/已故 | 友好提示 |
| 球员未参赛 | 球员参赛验证 | 退役/国家队未参赛/未入选 | 友好提示 |
| 球员大名单待确认 | 球员参赛验证 | 大名单未公布 | 提示 + 进入球员模式 |
| 赛事前瞻 | 第二层（日期 + 参赛验证） | 当前 < 06-11 且确认参赛 | 分组概况 / 大名单 / 出线前景 / 核心球员 / 历史底蕴 |
| [A] 赛前·首战 | 第三层 v2 | 赛事进行中 + 0 场已踢 | 前瞻五件套 + 赛程表 |
| [B] 复盘+前瞻 | 第三层 v2 | 赛事进行中 + ≥1 场已踢 + 有下一场 | 最近一场复盘 + 下一场前瞻 |
| [C] 赛事复盘 | 第三层 v2 | 赛事进行中 + 已淘汰 | 战绩 / 关键比赛 / 出局归因 / 总结 |
| [D] 赛前·淘汰赛 | 第三层 v2 | 赛事进行中 + 已出线 + 对手已定 | 晋级路径 + 前瞻 |
| [E] 出线等待 | 第三层 v2 | 赛事进行中 + 已出线 + 对手未定 | 出线确认 + 潜在对手分析 |
| [F] 小组收官 | 第三层 v2 | 赛事进行中 + 踢完 + 出线未定 | 最后一场复盘 + 积分/跨组对比 |
| 世界杯复盘 | 第二层（日期） | 当前 > 07-19，球队/球员/教练 | 世界杯旅程 / 表现 / 高光时刻 |
| 历史（有世界杯经历） | 第二层或第三层 | 确认未参赛 + 有参赛历史 | 历届记录表 + 经典比赛回顾 + 履历总结 |
| 历史（从未参赛） | 第二层或第三层 | 确认未参赛 + 从未进过决赛圈 | 说明从未参赛 + 预选赛出局情况 |
| 球员 | 叠加层 | 输入含球员名（通过参赛验证） | 球队模式 + 球员聚焦段 |
| 教练 | 教练验证 | 执教参赛国家队 | 执教履历 / 胜率 / 世界杯记录 / 战术风格 / 展望 |

## 安装

以下两种方式任选其一：

### 方式一：让 Agent 直接安装（推荐）

把本仓库链接发给 QoderWork / Qwen Code / Claude Code 等支持 Agent Skills 的助手：

```
请安装这个 Skill：https://github.com/realanthonysu/worldcup-analyzer
```

Agent 会自动将其克隆到技能目录并加载。

### 方式二：使用 npx skills 命令安装

```bash
npx skills add https://github.com/realanthonysu/worldcup-analyzer --skill worldcup-analyzer
```

安装完成后刷新 Agent（执行 `/skills` 确认列表中显示 `worldcup-analyzer`）。
